2. Descarga Directa en Web

Si ejecutas el servidor incluido (python3 server.py), el botón Descargar ahora procesa el video con yt-dlp y guarda el archivo MP4 o MP3 directo en tu equipo.

Conexión con motor yt-dlp

Dado que GitHub Pages aloja sitios estáticos, el generador de comandos funciona siempre sin servidores. Para habilitar también la descarga directa del archivo en el navegador, conecta el backend local o remoto con yt-dlp:

¿Cómo iniciar el servidor local incluido?

En la carpeta de este proyecto ejecuta:

python3 server.py

Esto activa el motor yt-dlp en http://localhost:8000 con permiso CORS para funcionar incluso desde tu página publicada en GitHub Pages.
